The files in this directory are derived from Adobe's Core 14 AFM files by
tools/generate-standard-fonts.php. They are modified: the metrics are re-encoded
to WinAnsiEncoding (Symbol and ZapfDingbats keep their built-in encodings),
reduced to the header values, advance widths and kerning pairs, and written as
PHP arrays. Each file retains the copyright notice of the AFM file it was
derived from.
